* 需要搭配[MODLOADER][JML]使用  
* 需搭配[Degrees of Lewdity 中文本地化][DOLCN]使用  
* 需搭配[Simple Framework][SF]使用或[maplebirchframework][MF]  


# 萬物皆可種農場  
**功能：**  
* **為Degrees-of-Lewdity新增要素：**  
  * 在工業區增加一個可以生產任何商品的生產基地。
  
# 更新日誌
**0.21**
* 優化種植系統相關程式碼，清理舊版種植系統拆分後遺留的不必要代碼。
    - 移除目前已不再使用的舊版種植功能及重複處理邏輯，簡化新版物品相容及收成流程。
    - 修正部分初始化資料不必要寫入存檔的問題。
    - 修正部分設備升級時可能重複新增設備的問題。
* 修復部分短週期物品實際成熟時間長於設定天數的問題。
    - 原版種植階段機制無法正確處理低於最低成長週期的物品，現在會依設定的實際生長天數修正成熟時間。

**0.20.5**
* 優化農場設備升級相關程式碼。
    - 將大量重複的設備升級、解鎖及重建流程改為查表及共用邏輯，有效縮減程式碼長度及降低後續擴充難度。
* 修復部分設備撬鎖解鎖時可能報錯的問題。
* 修復重新整理農場設備配置時，水產養殖槽及海水槽被錯誤建立為萬能料理機的問題。

**0.20.4**
* 修復新版遊戲中，進入農場後可能導致物品庫存異常消失的問題。
    - 修正舊版物品資料的相容處理，現在僅會在需要時暫時建立，使用完成後立即清除。
        - 避免殘留的舊版資料在存檔或重新載入遊戲時觸發新版的資料遷移機制。
    
**0.20.3**
* 修復新版遊戲中部分物品種植後，換日時可能無法正常成長的問題。
    - 使用舊版資料庫補齊種植資料時，同步補齊新版物品資料庫缺少的：成長天數、種植環境、產量倍率及季節等必要資料。

**0.20.2**
* 修復所有可種植物品直接解鎖的問題。
    - 現在必須持有至少一個對應物品，進入農場後才會解鎖該種植選項。

**0.20.1**
* 新增新版物品相容工具函數，後續新增可種植物品時僅需補充相容資料即可。
* 新增新版物品 烤布蕾、舒芙蕾 的種植支援。

**0.20**
* 支援遊戲版本`0.5.10.12`
    - 因新版遊戲資料庫變更，刪除許多對本模組來說必要的項目，目前僅能以舊版資料庫做補齊，~~未來新增新的物品時可能無法種出來~~。

**0.15**
* 支援`maplebirch`版本`3.2.5`
    - 不向下支援，需更新`maplebirch`
    
**0.14.2**

**0.14.1**

**0.14**

    * 把迴圈後的巢狀if、switch優化成查表形式的邏輯，有效縮減程式碼長度及降低後續擴充難度。 
      
**0.13.1**

* 使用者沒安裝`simple framework`、或`maplebirch framework`或安裝框架版本低於要求：  
    (1)版本不符合需求 => 彈窗警告
